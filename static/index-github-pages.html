ℹ️ NEXUS — Demonstração

🧠 Bem-vindo ao NEXUS v3.0

Esta é uma Página Estática

Você está visualizando uma versão estática do NEXUS hospedada no GitHub Pages. Para usar a versão completa com backend funcionando, você precisa executar localmente ou hospedar em um serviço como Render, Railway ou Vercel.

🚀 Como Usar

1. Localmente (Recomendado)

git clone https://github.com/Blackhatfenix/nexus-agent
cd nexus-agent
pip install -r requirements.txt
python3 app.py
# Acesse http://localhost:8000

2. Render (Gratuito)

  1. Vá para render.com
  2. Clique "New +" → "Web Service"
  3. Conecte seu repositório GitHub
  4. Configure:
    • Build Command: pip install -r requirements.txt
    • Start Command: python3 app.py
  5. Clique Deploy

3. Railway (Gratuito)

  1. Vá para railway.app
  2. Login com GitHub
  3. "New Project" → "Deploy from GitHub repo"
  4. Selecione nexus-agent
  5. Railway faz tudo automaticamente

4. Vercel (Gratuito)

  1. Vá para vercel.com
  2. Clique "Add New" → "Project"
  3. Import seu repositório
  4. Vercel detecta automaticamente e faz deploy
